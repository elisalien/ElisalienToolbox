# ElisalienOS | Freebies

> A single retro-desktop web page that gathers Elisalien's free resources for VJs and visual artists.

![Platform](https://img.shields.io/badge/platform-Web-informational) ![Stack](https://img.shields.io/badge/stack-HTML%20%2F%20CSS%20%2F%20JS-orange)

## About

A simple static page used to store and share links to Elisalien's free tools and content. It is styled as an old-school desktop: one "Elisalien's Freebies.exe" window with pixel-art buttons over a pastel pixel-art wallpaper, and a taskbar at the bottom.

## Features

Links to the following freebies:

- **CRT Text visualizer** — <https://elisalien.github.io/crt-text/>
- **Free Resolume Loops** — <https://2031452099936.gumroad.com/l/Elisalien_linepatterns>
- **Free Resolume Sources 1** — <https://2031452099936.gumroad.com/l/ISFResolumeSources_10>
- **Old School Windows GIF Visualizer** — <https://elisalien.github.io/gif98/#index>

Plus a retro window with title-bar buttons, a taskbar with a "START" button and a live clock.

## Getting started

No build step and no dependencies to install: open `index.html` in a browser, or host it on any static host.

## Tech stack

HTML, CSS, vanilla JavaScript, [Pixelify Sans](https://fonts.google.com/specimen/Pixelify+Sans) (Google Fonts). The wallpaper image is loaded from an external URL (`--background-url` in `index.html`).
